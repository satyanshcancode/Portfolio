# Satyansh Singh — portfolio

An original portfolio built with React, TypeScript, Three.js and GSAP (free core + ScrollTrigger only).

## Run it

```bash
npm install
npm run dev        # local preview at http://localhost:5173
npm run build      # production site in dist/
```

## Edit it

- `src/data/content.ts` — all text: bio, projects, training, tools, certificates, links.
- `src/index.css` — colours and fonts are the variables at the top of the file.
- `src/scene/network.ts` — the 3D network in the background.
- `src/App.tsx` — page sections and scroll animation.

## Deploy it

Push to GitHub and import the repo in Vercel or Netlify (build command `npm run build`, output `dist`).
